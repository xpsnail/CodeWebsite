# CodeWebsite 项目说明文档

## 1. 项目概述

CodeWebsite 是一个纯静态网页项目，用于对外发布健康宣教资料。当前已收录郑州市第三人民医院心血管内科病区《高血压患者出院指导》。

访问者打开首页后，点击「高血压」，即可在当前页面阅读完整指导内容。原文中的 Markdown 加粗（如 **膳食限盐**）会以粗体显示，不再跳转到外部 PDF。

| 项目 | 说明 |
| --- | --- |
| 项目名称 | CodeWebsite |
| 技术形态 | 单页静态网站（HTML + CSS + JavaScript） |
| 构建工具 | 无，不需要 Node.js、npm 或打包 |
| 后端/数据库 | 无 |
| 默认入口 | `index.html` |

## 2. 仓库与访问地址

## 3. 功能说明

### 3.1 首页

- 标题：云笔记公开资料
- 提供「高血压」按钮
- 点击后切换到出院指导正文，不离开当前页面，也不打开新标签

### 3.2 出院指导页

- 标题：高血压患者出院指导
- 来源：郑州市第三人民医院心血管内科病区
- 共 7 条指导，涵盖主食、限盐、烟酒、膳食结构、有氧运动、情绪控制、心理平衡
- 第 2 条包含「减盐窍门」「饮食原则」两个子块
- 加粗标题使用 `<strong>` 渲染，对应原稿中的 `**加粗**`
- 点击「返回」回到首页

### 3.3 阅读体验

- 适配手机与桌面宽度
- 按钮高度不少于 48px，便于点击
- 支持键盘焦点描边
- 系统开启「减少动态效果」时，关闭按钮位移动画

## 5. 页面结构与实现

`index.html` 是单文件站点，样式和脚本都写在同一个文件里，方便托管。

### 5.1 两个视图

| 区域 | 元素 | 初始状态 | 作用 |
| --- | --- | --- | --- |
| 首页 | `#home` | 显示 | 资料入口 |
| 正文 | `#guide` | 隐藏（`hidden`） | 出院指导全文 |

点击「高血压」执行：

1. 隐藏 `#home`
2. 显示 `#guide`
3. 页面滚动到顶部

点击「返回」则反向切换。

### 5.2 加粗格式如何保留

原稿使用 Markdown 加粗语法，例如：

```markdown
**膳食限盐**
**减盐窍门**
**饮食原则**
**限制饮酒与咖啡，提倡戒烟**
```

静态页中转换为 HTML：

```html
<strong>膳食限盐</strong>
```

并使用 CSS 加粗、加深颜色，保证阅读时能明显区分条目标题和正文。

小于号（如 `<5支/日`、`<30%`）已转义为 `&lt;`，避免被浏览器当成 HTML 标签。

### 5.3 正文条目

1. 主食以粗粮为主，七到八分饱，少吃甜食
2. **膳食限盐**，以及减盐窍门、饮食原则
3. **限制饮酒与咖啡，提倡戒烟**
4. **合理膳食，吃的恰当，身体健康**
5. **增加及保持适量有氧运动**
6. **情绪控制**
7. **心理平衡指导**

## 6. 本地预览

任选一种方式即可。

### 方式一：直接打开文件

用浏览器打开仓库根目录下的 `index.html`。

### 方式二：本地静态服务

在仓库根目录执行：

```bash
python -m http.server 8765
```

然后访问：

```text
http://127.0.0.1:8765/
```

操作检查：

1. 首页能看到「高血压」按钮
2. 点击后出现《高血压患者出院指导》
3. 「膳食限盐」等标题为粗体
4. 点击「返回」回到首页
5. 页面中不再出现 PDF 外链

## 7. 部署说明

### 7.1 GitHub Pages（当前对外访问）

1. 将代码推送到 GitHub 仓库 `xpsnail/CodeWebsite` 的 `main` 分支
2. 仓库 Settings -> Pages
3. Source 选择 Deploy from a branch
4. Branch 选择 `main`，目录选择 `/ (root)`
5. 保存后等待 1 到 2 分钟
6. 访问 https://xpsnail.github.io/CodeWebsite/

更新站点：修改 `index.html` 后提交并推送到 `main`，Pages 会重新构建。

### 7.2 Gitee 仓库（源码托管）

Gitee 仓库地址：https://gitee.com/xpsnail/code-web-site

默认分支为 `master`。将当前 `main` 分支同步到 Gitee：

```bash
git push origin main:master
```

如需在 Gitee 开通对外网页：

1. 登录 Gitee
2. 打开仓库，点击顶部「服务」
3. 选择「Gitee Pages」
4. 部署分支选 `master`，目录选 `/`
5. 点击「启动」

若「服务」中没有 Gitee Pages，或提示需要实名认证，则只能继续使用 GitHub Pages 对外访问。

## 8. 如何新增一条资料

当前只有「高血压」一条。若要增加其他病种或宣教资料，建议按同样模式扩展：

1. 在首页 `#home` 增加一个按钮
2. 增加对应的 `<article>` 正文区域，默认 `hidden`
3. 把原稿中的 `**加粗**` 写成 `<strong>加粗</strong>`
4. 为新按钮绑定显示/隐藏逻辑
5. 本地预览确认后，推送到 GitHub `main` 和 Gitee `master`

保持单页、无构建的结构，便于继续用 Pages 托管。

## 9. 设计说明

页面采用偏医疗、高对比、易读的视觉方案：

- 主色：青色 `#0891B2`
- 强调/按钮：绿色 `#059669`
- 背景：浅青 `#ECFEFF`
- 正文字号：16px 及以上
- 正文字体：Noto Sans SC
- 标题字体：Figtree + Noto Sans SC

目标是让出院指导在手机上也能清楚阅读，而不是做成装饰性海报。

## 10. 注意事项

1. 本站只托管静态文件，不能运行 PHP、Python 接口或数据库。
2. 首页文件必须叫 `index.html`，否则 Pages 访问根路径会 404。
3. 资源路径请使用相对路径，不要写本机绝对路径。
4. 本页内容属于健康宣教，不能替代医生面诊。
5. `_dev_scratch/` 仅用于本地临时文件，不要提交密钥或凭据。
